# 钩子公式库

## 上行公式（8 式）：让人对号入座

| 式 | 模板 | 例子 |
|----|------|------|
| 场景锚点 | 在你______之前 | 准备 Kira 面试前 |
| 反常识反问 | 明明______，为何______？ | 均分 95+ 为何被多大秒拒？ |
| 崩点复现 | 一______就______？ | 倒计时一响就脑子空白？ |
| 揭评分黑箱 | ______看______，只看______ | 招生官看面试视频，真的只看前 15 秒 |
| 群体点名 | 申请______的/想______的 | 想在加拿大读医？ |
| 痛点自白 | ______平平无奇？ | 课外活动平平无奇？ |
| 时限压迫 | ______分钟/秒 写出______ | 10 分钟写出高分文书 |
| 代价警告 | 别在______上交学费 | 千万别在选专业上交学费 |

**选用原则**：能具体到某一秒/某一句/某一分数，就用第 2、3、4 式；受众是泛人群时用第 5、7 式。

## 下行公式（6 式）：给一句听劝就有用的话

| 式 | 模板 | 例子 |
|----|------|------|
| 劝告 | 请先听我一句劝 / 你只需要______ | 你只需要这套节奏 |
| 禁令 | 千万别/别把______ | 别把领导力写成流水账 |
| 悬念指向 | 他们踩了这道______ | 他们踩了这道死穴 |
| 揭内幕 | 真的只看______ | 真的只看前 15 秒 |
| 给方法 | 记住这个______ | 记住这个万能公式 |
| 承诺转化 | 如何救活你的______ | 如何救活你的 UBC 文书 |

**搭配策略**（上行 → 下行）：
- 反问式上行 + 悬念/揭内幕下行 → 适合信息差内容（评分机制、录取逻辑）
- 场景锚点上行 + 劝告/禁令下行 → 适合避坑内容（常见错误、雷区）
- 痛点自白上行 + 承诺转化下行 → 适合操作方法内容（写作技巧、框架）

## 封面排版适配（1080×1260）

