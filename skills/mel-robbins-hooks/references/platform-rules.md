# 三平台适配规则

同一套两行钩子，落到不同平台时的处理差异。

| 平台 | 主力人群 | 语气 | 字数限制 | 处理要点 |
|------|---------|------|---------|---------|
| 小红书 | 18–30 留学生/准留学生 | 强钩子 + emoji + 口语化 | 标题 ≤ 20 个中文字或英文单词 | 正文第一行就是钩子；emoji 放句尾 1 个；标签大词 + 精准词混搭（4–5 个） |
| 视频号 | 30–55 家长为主 | 有品质感、值得转发 | 封面 ≤ 2 行、每行 ≤ 12 字 | 少 emoji；下行做成能引发转发的判断句（"这条值得转给家长"） |
| YouTube | 国际学生（英文） | SEO 关键词前置 + 数字 | 标题 ≤ 70 字符 | 关键词放前 40 字符；描述前两行是关键；附 tags |

## 各平台组装方式

**视频号封面**（1080×1260）
```
[品牌条] 苏苏留学有话说            加拿大留学
 EP.01 ■ KIRA INTERVIEW
 准备 Kira 面试前                    ← 上行 浅灰 52px
 ─────────────────────────
 请先听我一句劝                      ← 下行 纯黑 104px（超宽自动缩）
 [请先听我一句劝]                     ← 红色行动块 ≤6 字
 ─────────────────────────
 系列名                        第 01 集
```

**小红书图文**
- 标题取钩子压缩版：`面试别见光死？Kira 通关秘籍🤖`
- 正文：`上行句子 + 一句延展 + 悬念收尾`，标签放末尾
- 图片：3:4 最佳；6:7（1080×1260）可用但会留边，关键文字务必居中，别压到上下裁切区

**YouTube**
- Title：`Kira Interview: Please Read This Before You Start`
- Description 前两行放钩子，后面放章节/资源链接
- Tags：品牌词 + 通用词 + 长尾词，8–12 个

## 发布节奏建议

同一系列多条内容连发时，每条间隔 ≥ 30 秒；小红书对该 IP 有风控历史的网络环境下建议拉到 60–120 秒，并优先采用「仅自己可见」先沉淀、人工检查后再转公开。
