# Mel Robbins 爆款钩子文案

把「信息陈述型」标题，改成「对一个人说话」的两行钩子。适用于视频号封面、小红书图文标题、短视频口播开场、YouTube 标题。

## 核心结构：两行钩子

```
上行 = 场景锚点 / 痛点反问   →  让人对号入座："这是在说我"
下行 = 大白话劝告 / 禁令     →  给一句听劝就有用的话
```

中间用换行或 `➔` 连接。做封面时上行用小字浅色、下行用大字高对比（视觉层级 = 读完就走的行为路径）。

**成品范例**
```
准备 Kira 面试前        ← 上行：场景锚点，有具体动作
请先听我一句劝          ← 下行：一句劝告，勾起"什么劝？"
```

```
均分 95+ 为何被多大秒拒？ ← 上行：反常识反问（高分不该被拒）
他们踩了这道死穴        ← 下行：给悬念 + 指向解法
```

```
申请约克舒立克商学院
别把领导力写成流水账      ← 禁令式，比"要注意写法"强 10 倍
```

## 八条铁律

| # | 规则 | 反例 | 正例 |
|---|------|------|------|
| 1 | **主语是具体的人**，不是"学生/申请人/用户" | 留学申请人应如何准备面试 | 准备 Kira 面试前，请先听我一句劝 |
| 2 | **写大白话**，删掉所有书面语 | Kira 面试通关秘籍与实战指南 | 你就当对面坐着一个招生官，别背书 |
| 3 | **要有画面**，能被想象出来 | 提升面试表现力 | 倒计时一响就脑子空白？记住这个万能公式 |
| 4 | **给禁令 > 给建议** | 注意文书的条理性 | 千万别把领导力写成流水账 |
| 5 | **具体数字/时限**，不要模糊量化 | 招生官很快就形成印象 | 招生官真的只看前 15 秒 |
| 6 | **留缺口**：上行给痛点，下行给方向但不给答案 | 5 步搞定 Kira 面试（已说完） | 记住这个万能公式（答在视频里） |
| 7 | **不要假装提问**：反问必须能被真实回答 | 你的面试准备好了吗？（没人回答） | 均分 95+ 为何被多大秒拒？（有明确对象） |
| 8 | **跨平台控制字数**：小红书 ≤ 20 个中文字/英文单词，视频号封面 ≤ 2 行 12 字/行 | — | — |

## 工作流

1. **拆原素材**：列原始标题 → 找出「核心冲突」（受众怕什么 / 输在哪 / 被谁筛掉）。
2. **写上行**：把冲突写成一句能被代入的场景。优先用「具体动作 + 数字/时限 + 反常识结果」。
3. **写下行**：给出一句劝告 / 禁令 / 承诺。动词开头或"别/千万别"开头最有力。
4. **过黑名单自查**：跑 `scripts/lint_copy.py`（检测机构感词汇 + 字数 + 是否缺钩子）。
5. **三平台适配**：见 `references/platform-rules.md`。
6. **批量产出成对同行对照表**（原标题 → 新钩子），交给用户挑，不要只给一版。

**默认一次给 2–3 个候选**（禁令型 / 反问型 / 承诺型各一），让用户选语气，不要替用户决定。

## 严禁写作（机构感黑名单）

命中任意一个就该重写：
`秘籍` `指南` `攻略` `宝典` `全解析` `深度剖析` `赋能` `助力` `闭环` `抓手` `体系` `方法论` `打通` `提升XX力` `解读` `漫谈` `浅析`

这些词是"编辑在写"，不是"人在说话"。
